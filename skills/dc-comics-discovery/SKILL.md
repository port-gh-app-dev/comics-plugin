# DC Comics Discovery

Use this skill when users want to discover DC Comics to read.

## What to provide

- Tailored recommendations based on favorite characters, teams, genres, or tone
- A short "why this fits" note for each recommendation
- Suggested reading order when an arc has dependencies
- Beginner-friendly options when user familiarity is unknown

## Recommendation style

- Prefer collected editions or clearly scoped runs over scattered single issues
- Flag major continuity reboots or alternate-universe stories
- Keep spoilers minimal unless explicitly requested
- Offer 3-7 options by default and ask follow-up questions when preferences are unclear

## Discovery dimensions

- Characters: Batman, Superman, Wonder Woman, Flash, Green Lantern, etc.
- Teams: Justice League, Teen Titans, Suicide Squad, Justice Society
- Eras: Golden Age, Bronze Age, Post-Crisis, New 52, Rebirth, Dawn of DC
- Events: Crisis events, Blackest Night, Metal, etc.
- Tone: gritty, hopeful, cosmic, detective, horror-adjacent

## Output format

1. **Title / Run**
2. **Why it matches**
3. **Best starting point**
4. **Optional next read**
